# Helixfa Desktop

Downloads for **Helixfa Provider Console**, the counter app for Helixfa businesses. Use it to take walk-in orders and appointments, print receipts, and get an alert for every new order.

| Platform | Latest version |
|---|---|
| macOS (Apple silicon · Intel) | [Helixfa-macOS-universal.dmg](https://github.com/Foshati/helixfa-desktop/releases/latest/download/Helixfa-macOS-universal.dmg) |
| Windows 10 · 11 | [Helixfa-Windows-x64-setup.exe](https://github.com/Foshati/helixfa-desktop/releases/latest/download/Helixfa-Windows-x64-setup.exe) |
| Linux (AppImage) | [Helixfa-Linux-x86_64.AppImage](https://github.com/Foshati/helixfa-desktop/releases/latest/download/Helixfa-Linux-x86_64.AppImage) |
| Linux (Debian · Ubuntu) | [Helixfa-Linux-amd64.deb](https://github.com/Foshati/helixfa-desktop/releases/latest/download/Helixfa-Linux-amd64.deb) |

Every release lists SHA-256 checksums in `SHA256SUMS.txt`. This repository holds releases only. Builds are produced automatically from the Helixfa source repository.
